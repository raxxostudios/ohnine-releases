# OhNine releases

Downloads and the update feed for OhNine, the Mac menu bar app that shows your
Claude usage limits. This repository holds signed builds only, no source.

Download: https://studio.raxxo.shop/ohnine-download

- **2.0 and later:** macOS 14 or later, Apple silicon and Intel, signed and
  notarized by Apple. The app updates itself from `appcast.xml` in this repo.
- **1.1.0:** the last build for Windows, Linux and macOS 12 and 13. It keeps
  working but gets no further updates.
